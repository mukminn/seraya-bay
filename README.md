**Seraya Bay: Golden Hour** — an original open-world crime game for the browser. Explore a tropical coastal city on foot and by car, run a six-mission story as Bimo, a courier framed by the Black Current syndicate, steal and drive cars, fight with fists, feet and found-or-bought weapons, and outrun a wanted system with police who chase on foot and by car. Built with three.js, fully procedural (no external assets), playable on desktop and on a phone in landscape with touch controls.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser (or serve the `game/` folder with any static file server).
